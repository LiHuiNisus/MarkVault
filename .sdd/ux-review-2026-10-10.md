# MarkVault 用户模拟评测报告

日期：2026-10-10
方法：6 个独立评测 subagent 分别扮演不同用户角色，只读走查 `ui/` 与 `src-tauri/src/`，
逐条给出 `file:line` 证据。未运行应用，结论均为代码级判定。

角色与总评：

| 角色 | 评分 | 一句话 |
|------|------|--------|
| 首次使用新手 | 放弃率中 | 核心链路通，但"文件在哪/怎么删/两个文件夹"全藏在悬停与右键里 |
| 键盘流重度用户 | 3/10 | 离开 textarea 寸步难行：列表零键盘、菜单选不中、无插入类快捷键 |
| 资料整理型用户 | 5/10 | 无多选、不能批量移动/导入，标签不能改不能合并 |
| 长文写作者 | 5/10 | 每键全量重渲染 + 按百分比滚动同步，长文卡且三处对不齐 |
| 导出/分享型用户 | 5/10 | PNG 只截一屏、导出名与标题对不上、"复制当前文档"名不副实 |
| 容错/防错审查 | 数据安全中 | 两条真实丢数据路径：换库前不保存、关窗保存失败仍强关 |

## P0（阻塞或丢数据，必须修）

### 1. 更换笔记库前不保存 → 丢失未落盘编辑
`ui/app.js:1455-1465`。`btn-vault-dir` 选完目录直接 `set_config` + `location.reload()`，
无 `doSave`、无 `beforeunload`。防抖窗口内（2s）的编辑随重载消失。
对比：关窗路径 `ui/app.js:1468-1477` 有正确 `doSave`。
修法：切换前 `if (state.dirty) await doSave()`，失败则中止；加确认框说明不自动迁移。

### 2. 关窗保存失败仍强制关闭 → 整篇丢失
`ui/app.js:1468-1477`。`doSave` 的错误被自身吞掉，外层 `try{...}finally{ invoke('close_window') }`
保证无论如何都关窗。磁盘满/只读/路径失效时，内存内容与磁盘都不留。
`src-tauri/src/lib.rs:44-49` 拦截后放行 destroy。
修法：`doSave` 返回成败；仅成功才 `close_window`；失败保持窗口并给可操作错误框。

### 3. 重命名文件夹后自动保存写回旧路径 → 笔记分裂成两份
`ui/app.js:721-734`。`renameFolderFlow` 只更新 `activeFolder`，未同步 `state.current.file_name`。
下次 `doSave`（`ui/app.js:166-190`）按旧前缀 `旧名/xx.md` 写入，
`store::write_note` 的 `create_dir_all`（`src-tauri/src/store.rs:202-212`）把旧文件夹重建，笔记新旧两份。
修法：改名成功后把 `state.current.file_name` 前缀从旧名换成新名，并同步 `last_open`。

### 4. 每键全量重渲染 → 长文输入卡顿
`ui/app.js:1309-1313`。`onEditorInput` 同步调用 `renderHighlight()`（重建高亮层 + gutter，
逐行读 `offsetHeight` 强制回流）+ `render()`（`marked.parse` 全文 + `DOMPurify` 全文 +
重建大纲 + 字数）。input 无防抖/rAF/增量。
修法：highlight 与 preview 走 rAF 合并；preview 解析加 ~100ms 防抖；gutter 高度改 CSS。

### 5. 下拉菜单键盘无法选中
`ui/index.html:32-36,102-104,121-126,141-142`；`ui/app.js:908-929`。菜单项全是
`<div class="dropdown-item">`，无 `tabindex`、无方向键/Enter 处理。
修法：菜单打开后聚焦首项，接管 ArrowUp/Down/Home/End/Enter/Esc。

### 6. 笔记列表零键盘操作
`ui/index.html:64`；`ui/app.js:585`。`<ul id="note-list">` 无 `tabindex`、无 keydown，
列表项只有 `li.onclick`。
修法：列表加 `tabindex="0"` + `role="listbox"`，方向键移动、Enter 打开、
F2 重命名（复用 `startInlineRename`）、Delete 删除（复用 `deleteNoteFlow`）。

## P1（明显不便或需用户自己留心）

### 数据与整理
- 删除非空文件夹在搜索筛选下会"搬一半就报错"：`ui/app.js:738-761` 按 `state.notes` 统计成员，
  搜索态下该数组只是命中子集。修法：删除前取全量列表算成员。
- 删除笔记入口只在悬停图标里，右键菜单无删除项：`ui/index.html:210-217`、`ui/app.js:265-269`。
- 删除是永久删除，无回收站无撤销：`ui/app.js:517-524`、`src-tauri/src/store.rs:214-217`。
  修法：移到 vault 下 `.trash/`。
- 内联重命名失焦即提交：`ui/app.js:513`。修法：失焦改取消。
- 自动保存纯尾随防抖无最大等待，连续写作可能长时间不落盘：`ui/app.js:159-164`。
- 自动保存失败只在顶栏一行小字且会被后续 `setStatus('就绪')` 覆盖：`ui/app.js:182-189,851`。
- 无多选/批量移动/批量导入：`ui/app.js:241,288-292,591`；`src-tauri/src/commands.rs:274-280` 只支持单文件选择。
- 点标签走的是全文搜索而非按标签过滤，会把正文含该词的文章带出：`ui/app.js:280,825`、`ui/app.js:813-814`。
- 标签栏无 max-height/滚动，标签多了把笔记列表挤没：`ui/style.css:409-415`。
- 标签不能重命名/删除/合并：`ui/app.js:811-828`。
- 文件夹不支持嵌套但界面零提示，输 `/` 静默打回"非法名称"：`ui/app.js:698-702`、`src-tauri/src/store.rs:146-158`。
- 拖拽落点只绑文件夹标头那一行，拖到文件夹笔记区无反应：`ui/app.js:356,455-471`、`ui/style.css:385`。
- 无按文件夹筛选：`ui/app.js:418-423`、`src-tauri/src/commands.rs:180-205`。

## 已经做对、不要动的部分

- 移动/改名从不静默覆盖：`dedup_name` 追加序号（`src-tauri/src/commands.rs:48-60`）+
  `store::move_note` 目标存在即报错（`src-tauri/src/store.rs:227-229`）。
- 删除文件夹绝不连带删笔记：后端拒绝非空（`src-tauri/src/store.rs:263-274`），
  前端先把笔记移到根目录再删。
- 路径穿越防护严格：`validate_segment` / `validate_rel_path` 拦下 `../`、盘符、ADS 冒号。
- 自动保存不吃撤销栈：`doSave` 从不回写 textarea，格式操作走 `execCommand('insertText')` 保留原生 undo。
- 剪贴板写入正确：文件用 `CF_HDROP`，路径用 `CF_UNICODETEXT`，占用时重试。
- 导出的 `.md` 干净，不含 frontmatter。
- 关闭窗口有兜底保存方向正确（只漏了失败分支）。
